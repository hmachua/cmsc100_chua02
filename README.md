## Steps on How to Create a GitHub Page
**Step 1**: Create your remote repository.

**Step 2**: Clone the repository you created to your local computer/machine in order for you to add customizable HTML and CSS. (Make sure to follow the proper structure of of cloning.)

**Step 3**: Do not forget to configure your local repository by setting your own username and email as this helps track who pushes certain changes to the remote repository.

**Step 4**: Now, create your index.html file that you would push into your remote repository. This file will be the first page rendered in the root directory of the website.

**Step 5**: Also, make your remote Git repository visible to the public and configure the GitHub Pages through the settings by selecting which branch will host the website.

**Step 6**: You can now access your own website using github.io. Enjoy!
